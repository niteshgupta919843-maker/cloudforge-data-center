# Cloudforge Data Center

Create an actual working, responsive HTwoCloud marketing website, not an image or static mockup. Main feature: a compact premium 3D scroll-controlled data-center build sequence. Start with separated floating raw hardware components (CPU, RAM, SSD, motherboard, cooling fan, PSU, network switch) on a dark navy/electric-blue stage. As the user scrolls, components assemble into one server, then a small server rack, then one complete modern data-center room/building with HTwoCloud branding. Keep it to a few elegant stages; no oversized visual clutter. Use React + TypeScript, Three.js/React Three Fiber, and GSAP ScrollTrigger (or robust equivalent) to synchronize the 3D animation with scroll. Use procedural 3D geometry if model files are unavailable; do not use a flat screenshot as the animation. Add a concise hero headline, navigation, service cards for Cloud Servers, Tally on Cloud, Managed Hosting, Secure Storage, Backup & Recovery, 24/7 Support, and a contact CTA. Premium enterprise design, dark navy and cyan blue, crisp typography, responsive mobile fallback, reduced-motion support, accessible controls, SEO metadata, lazy loading and performance optimization. Do not invent uptime, customer counts, certifications or other factual claims. Implement the site, run the production build, and fix errors.
